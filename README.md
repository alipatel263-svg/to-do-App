# To-Do App

Task and appointment management workspace built with React, Redux Toolkit, Bootstrap, Formik, and Yup.

## Features
- User registration and login flow
- User dashboard and to-do / appointment management
- Search and filter support
- State management using Redux Toolkit store, slices, hooks, and services

## Tech Stack
- React & Vite
- Redux Toolkit
- Bootstrap, Formik & Yup
- JavaScript (JSX) & CSS
